# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Дополнительные элементы

- `sitemap.xml` - простая карта сайта;
- Open Graph-теги - базовая разметка для отображения ссылок.

## Используемые технологии

- HTML;
- CSS;
- Git;
- GitHub.

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

### Адаптивные решения

- добавлен отдельный файл `css/responsive.css`, подключён на всех страницах после `style.css`;
- применён подход Mobile First;
- медиазапросы: 430px, 768px, 1024px, 1440px;
- шапка: на мобильном - бургер-меню, на планшете и desktop - горизонтальное;
- hero-блок: на мобильном - колонка, на 1024px+ - flex;
- сетка карточек: 1 → 2 → 3 колонки;
- фильтр: на мобильном фильтры сверху, на 1024px+ - сбоку (sticky);
- форма: на мобильном в одну колонку, на 768px+ - label слева, поле справа;
- таблица характеристик: на мобильном - карточки, на планшете+ - обычная таблица с `overflow-x: auto`;
- изображения: `max-width: 100%`, `height: auto`, `loading="lazy"`, `srcset` + `sizes` на `product.html`.

### Доступность

- добавлен skip-link «Перейти к основному содержимому»;
- видимый фокус (`:focus-visible`) у ссылок, кнопок, полей;
- у всех полей формы есть `<label>`;
- у изображений осмысленные `alt` (логотип - декоративный, `alt=""`);
- семантические `<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`, `<aside>`;
- один `<h1>` на страницу;
- навигация размечена через `<nav aria-label="Основная навигация">`;
- модальное окно `<dialog>` с `aria-labelledby`;
- `aria-label` на списках товаров исправлены.

### Проверенные ширины

360px, 430px, 768px, 1024px, 1440px - горизонтального скролла нет.
